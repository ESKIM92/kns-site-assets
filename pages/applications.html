제품군을 고르는 세 가지 질문

1

무엇을 알아야 하나요?

위치 · 각도 · 길이 → 엔코더 · 인디케이터 · 와이어 · 경사 센서. 유무 · 거리 → 센서. 치수 · 두께 · 품질 → 레이저 측정 · 검사기기. 진동 · 온도 · 충돌 → 예지보전 센서.

2

사람을 어떻게 지키나요?

개방 구역 접근 → 라이트커튼. 방호문 · 출입 → 안전 스위치 · 트랩키. 신호를 받아 멈추는 쪽 → 안전 릴레이 · 컨트롤러. 폭발 분위기 → Ex 형번(국내 사용 시 KCs 확인).

3

환경은 어떤가요?

세척 → 316 스테인리스 · IP69K. 분진 · 칩 → 자기식 측정. 충격 · 진동 · 옥외 → 앱솔루트 · 안전형 엔코더. 배선 불가 → 무선(BLE · NB-IoT). 클린룸 · ESD → ESD 대응 형번.
